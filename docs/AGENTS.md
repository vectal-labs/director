# Documentation

- Keep scope in `scope.md` and open decisions in `open-questions.md`. Write ADRs under `adr/` only when explicitly requested.
- Preserve dated evaluation results in `evals/`. Record new validation separately; never imply fixture tests prove live app behavior.
- Personal teaching belongs in root `profile/`; operational history belongs in root `state/`. Both are gitignored. `private/` is unrelated private storage.
